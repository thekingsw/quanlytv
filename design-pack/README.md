# Gói thiết kế lại Khóa TV
1. Đưa cả thư mục này vào thư mục gốc dự án (hoặc đặt cạnh) rồi cho Agent đọc.
2. Dán nội dung PROMPT.md cho Agent. Prompt tham chiếu các file còn lại.
Thư mục: design/ (HTML tham chiếu), screenshots/ (ảnh), design-tokens.json, DESIGN-SPEC.md, reference/ (phân tích app hiện tại).
