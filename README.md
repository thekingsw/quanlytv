# Khóa TV — README

App Android TV (Google TV) quản lý thời gian xem TV chung cho cả nhà, không dùng Family Link.

- Package: `vn.tvlock`, versionCode 23, versionName 3.0, minSdk 26, targetSdk 34.
- Ngôn ngữ: Kotlin, **View system (XML layout), không Compose, không AndroidX** — chỉ cần kotlin-stdlib + android.jar.
- APK: `~/workspace/your_files/tv-lock/khoa-tv.apk` (đã ký bằng debug keystore dùng chung trong `~/workspace/manual-build/debug.keystore`).
- Build thủ công: `~/workspace/manual-build/build_tvlock.sh` (không dùng Gradle — VM chặn Gradle daemon và Java HTTPS; compile bằng K2JVMCompiler trực tiếp, aapt2/d8/zipalign/apksigner từ build-tools 34.0.0).

## Build APK bằng GitHub Actions

Mỗi lần push code lên GitHub, GitHub Actions tự build file APK debug
(`.github/workflows/android.yml`, Gradle 8.7, JDK 17).
Vào tab **Actions** → chọn lần chạy mới nhất → tải file `khoa-tv-apk`
về rồi gửi sang TV cài đặt (cho phép cài từ nguồn không xác định).

Lưu ý: file workflow phải do anh tự thêm qua web GitHub (GitHub chặn app
tạo file workflow qua API). Các bản build CI đều ký bằng cùng một debug
keystore cố định (`android/app/debug.keystore.b64`) nên cài đè lên nhau được.

Lưu ý: đẩy code lên GitHub bằng snapshot-push chỉ nhận file text (UTF-8) —
ảnh nền (`android/app/src/main/assets/wallpapers/*.jpg`) và ảnh chụp màn hình
(`design-pack/screenshots/`, `docs/screenshots-launcher/`) là file nhị phân
nên KHÔNG có trên GitHub, chỉ nằm ở máy local. Muốn thêm ảnh lên remote thì
dùng git trên máy anh.

## Bản v4 (1.3) — lịch khóa linh hoạt theo ngày + giới hạn ngày theo ngày

- **Lịch khóa theo ngày:** thay khung khóa cố định bằng danh sách lịch (`lockSchedules`): mỗi lịch chọn ngày trong tuần + giờ từ–đến, gộp nhiều lịch (lịch nào khớp thì khóa). `startMin==endMin` = khóa cả ngày; `startMin>endMin` = qua đêm (19:00→10:00 hôm sau). UI: `SchedulesActivity` (danh sách + thêm mới) và `ScheduleEditActivity` (7 checkbox ngày, giờ bắt đầu/kết thúc ±15 phút, nút Khóa cả ngày, Lưu/Xóa). Migration: khung khóa cũ 21:00–07:00 hằng ngày thành một lịch. Khung thời sự 19:00–20:00 giữ nguyên, không nằm trong danh sách lịch.
- **Giới hạn ngày theo ngày:** `dailyLimits` — mỗi ngày trong tuần một mức (30/60/90/120/180/240 phút hoặc Không giới hạn = -1), đặt trong `DailyLimitsActivity`. Mọi chỗ dùng giới hạn ngày (khóa, cảnh báo 5'/1', màn hình chính, web, báo cáo) đều dùng `limitForToday()`. Migration: mức cũ 90' gán cho cả 7 ngày.
- Version: versionCode 4, versionName 1.3, cùng keystore ký cố định nên cài đè lên bản v3 được.

## Bản v3 (1.2) — giới hạn từng app, phút thưởng, nhắc nhẹ, báo cáo

- **#2 Giới hạn từng app:** quy tắc theo app (`appRules` trong Store): Bình thường / Giới hạn riêng 15/30/60 phút/ngày / Không tính giờ (app học) / Chặn hẳn. Đặt trên TV (Cài đặt → Giới hạn từng app); áp dụng ngay. Hết hạn nào trước thì khóa theo lý do đó; app thời sự trong khung thời sự được miễn trừ tuyệt đối (v2.9), còn các app khác trong khung tuân quy tắc bình thường (v2.10 bỏ chặn độc quyền của khung thời sự).
- **#4 Phút thưởng:** quỹ `bonusMin` không hết hạn khi sang ngày; hết giờ ngày thì trừ dần quỹ, hết cả quỹ mới khóa. Cấp từ web điện thoại (Thưởng +5/+10/+15/+30, không PIN) hoặc trên TV (Cài đặt → Phút thưởng, phải nhập PIN).
- **#5 Nhắc nhẹ trước khi khóa:** còn đúng 5' và 1' nữa là hết giờ ngày (tính cả thưởng), hết giờ riêng của app đang xem, hoặc đến giờ khóa thì hiện `WarningActivity` (banner trên, tự tắt sau 20 giây, bấm Đã hiểu/Back để tắt); mỗi mốc nhắc một lần cho mỗi lần tới hạn; không chặn việc xem.
- **#6 Báo cáo:** lịch sử 14 ngày (tổng phút + phút từng app) trong Store; web điện thoại có mục Báo cáo (bảng hôm nay theo app + 7 ngày gần nhất dạng thanh ngang) và endpoint `GET /api/report`; màn hình chính TV hiện "Hôm qua đã xem X phút".
- Version: versionCode 3, versionName 1.2, cùng keystore ký cố định nên cài đè lên bản v2 được.

## Bản v2 (1.1) — UI mới + ẩn icon khỏi launcher

## Giới hạn đã biết

- **Phải bật Accessibility** thì app mới chặn được app khác; nếu tắt, app chỉ còn đếm giờ/khóa qua dịch vụ nền.

## v2.3 (2026-10-28, versionCode 14) — Mã PIN web + cách đặt lại khi quên

Web điều khiển giờ yêu cầu mã PIN web (mã RIÊNG, khác mã PIN khóa TV, 4–6 chữ số). Lần đầu sau khi cập nhật, mã PIN web mặc định = mã PIN khóa TV hiện tại (vào web được ngay, không phải đặt mã mới); đổi mã PIN khóa TV sau này không làm đổi mã PIN web.

- `WebServer.kt`: phiên đăng nhập bằng token UUID ngẫu nhiên (map token → hạn, trong bộ nhớ, mất khi app/TV khởi động lại), hạn 30 ngày, cookie `tvlock_session` (HttpOnly, Path=/). Mọi route đều cần phiên, trừ file tĩnh `app.css`/`app.js` và `POST /api/webpin-login`, `/api/webpin-logout`. - Web (`assets/web/`): không làm trang đăng nhập riêng — `app.js` gọi `/api/status` khi khởi động, 401 thì hiện màn hình nhập PIN (ô nhập + nút "Mở khóa" + link "Quên mã PIN?" mở hướng dẫn đặt lại), nhập đúng thì tải lại dữ liệu bình thường; sai hiện lỗi ngay trên màn hình đó. - Đặt lại khi quên — cách 1 (trên TV): `SettingsRegistry` thêm mục thứ 9 "Mã PIN web" (Item thêm field `extraMode`, `SettingsRail` truyền kèm `putExtra("mode", ...)`) → `LockActivity` mode `"webpin"` (lý do "Xem mã PIN web", nhập đúng mã PIN khóa TV thì mở `WebPinActivity`) → `WebPinActivity` (rail+pane) hiện mã PIN web hiện tại cỡ lớn, đổi mã mới, hoặc "Đặt lại = mã PIN khóa TV".
- Đặt lại khi quên — cách 2 (qua Cài TV): `WebPinResetReceiver` (exported, action `vn.tvlock.RESET_WEBPIN`, theo đúng mẫu `AntiDisableReceiver`) đặt `webPin` = mã PIN khóa TV + Toast; Cài TV 1.7 thêm `AdbInstaller.resetWebPin()` + nút "Đặt lại mã PIN web" trong tab Chống tắt.

App Khóa TV giờ kiêm luôn launcher (màn hình chính) của TV — một app duy nhất, cài đè lên bản 2.11 là mọi cài đặt khóa giữ nguyên (prefs file `tvlock` và mọi key cũ không đổi). App launcher riêng "TV Home" (vn.tvhome) bản 1.0 đã bị thay thế, chỉ còn là kho tham khảo.

- **Màn hình chính kiểu Apple TV** (`HomeActivity`, intent HOME+DEFAULT, `singleTask`, không thêm LAUNCHER nên vẫn ẩn icon như cũ): đồng hồ to (TextClock) + ngày tháng tiếng Việt, thời tiết (nhiệt độ + mô tả + thành phố, Open-Meteo miễn phí không cần key, tải trên thread nền, refresh mỗi 30 phút, cache vào prefs để mở lên có ngay), hàng "⭐ Yêu thích" (ngang) + lưới 6 cột "Tất cả ứng dụng" (cuộn dọc). D-pad di chuyển, focus nhìn rõ (vòng sáng hổ phách + viền trắng + phóng 1.06, cùng họ với app khóa), OK mở app, **giữ OK** → menu: ghim/bỏ ghim yêu thích, ẩn app. Quét app: LEANBACK_LAUNCHER (+ LAUNCHER fallback), sắp xếp theo tên tiếng Việt (Collator), trừ `vn.tvlock`, tôn trọng danh sách ẩn. Không xin thêm quyền nào (INTERNET đã có từ trước).
- **Kiểu icon ứng dụng** (theo yêu cầu): Cài đặt → Màn hình chính → "Kiểu icon ứng dụng: Mặc định/Tròn" — Tròn = `CircleIconView` cắt tròn trong `onDraw`, Mặc định = icon gốc. Áp dụng cho cả lưới và hàng yêu thích.
- **Ảnh nền màn hình chính**: Cài đặt → Màn hình chính → Chọn ảnh (SAF, downscale ≤1920 JPEG 85, tái dùng `saveLockBgBytesTo`) / Xóa ảnh (về gradient tối mặc định).
- **Thành phố thời tiết**: Hà Nội (mặc định) / Đà Nẵng / TP.HCM — đổi thì xóa cache để tải mới ngay.
- **Ứng dụng đã ẩn**: `HiddenAppsActivity` (checkbox từng app, bấm để ẩn/hiện lại).
- **Tích hợp khóa (khóa vẫn như cũ, không sửa logic nào):** `vn.tvlock` vẫn trong danh sách loại trừ của Trợ năng; `HomeActivity` mỗi giây kiểm tra `Store.isLockedNow()` trong `onResume` (Handler, dừng ở `onPause`) — đang khóa thì mở `LockActivity` y hệt `GuardService.tick()` (cùng flags `NEW_TASK|CLEAR_TOP`, `reason` + `mode="lock"` + `wholeLock=true`). Chống mở chồng bằng cờ tĩnh `LockActivity.isShowing` (true ở onCreate, false ở onDestroy — chỉ thêm cờ, không sửa gì khác). Kết quả: bấm Home lúc TV bị khóa → màn hình khóa hiện lên như cũ (PIN, "Mở thời sự", mã thưởng...); mở khóa xong → về lại màn hình chính.
- **Đặt làm màn hình chính mặc định:** Cài TV → tab Lệnh ADB → `cmd package set-home-activity vn.tvlock/.HomeActivity`. Về lại launcher cũ: gỡ Khóa TV (không khuyến nghị — mất luôn khóa) hoặc đặt lại launcher cũ bằng lệnh tương tự với component của nó.
